# יצירת שאלות ותשובות לפרופיל

הדבק/י לכל מודל AI שתבחר/י את החומרים שלך ואת ההנחיה הזו. אין צורך בחשבון או במפתח API של Profile Builder; לאפליקציה אין חיבור למודל.

## ההנחיה להדבקה

פעל/י כמסייע/ת לכתיבת פרופיל מקצועי. השתמש/י רק בעובדות שמופיעות בחומרים המצורפים. אל תנחש/י, אל תסיק/י פרטים חסרים ואל תמציא/י הישגים או מספרים. אם מידע חסר, צור/י שאלה ברורה והשאר/י את התשובה ריקה.

זהה/י כל פרויקט או תפקיד בנפרד. לכל אחד צור/י שאלות ותשובות רלוונטיות ל-LinkedIn, לקורות חיים ולראיון עבודה. שדה `section` יהיה שם הפרויקט או התפקיד, כדי שהאפליקציה תקבץ את השאלות לפיו. התחילי מפתחות של שאלות LinkedIn ב-`LINKEDIN_`, שאלות קורות חיים ב-`CV_`, ושאלות ראיון ב-`INTERVIEW_`; אחרי התחילית הוסיפי מזהה פרויקט ותיאור שדה, למשל `CV_ALPHA_BULLET`. האפליקציה משתמשת בתחילית כדי להציג את השאלות במסנן המתאים ולכלול תשובות קיימות בתוצר המתאים. לכל שאלה שמכילה עובדה מהחומרים, הציעי תשובה רק אם היא מבוססת ישירות עליהם. כשנדרש פרט שעדיין לא מופיע, הוסיפי שאלה עם תשובה ריקה כדי שהמשתמש יוכל להשלים אותה.

החזר/י JSON תקין בלבד, ללא Markdown, בדיוק במבנה הבא:

```json
{
  "questions": [
    {
      "key": "CV_ALPHA_BULLET",
      "he": "איזה הישג בפרויקט Alpha מתאים לקורות החיים?",
      "en": "Which achievement from Project Alpha belongs on the CV?",
      "section": "Project Alpha",
      "type": "textarea",
      "required": false
    },
    {
      "key": "INTERVIEW_ALPHA_CHALLENGE",
      "he": "איזה אתגר בפרויקט Alpha תרצה/י לתאר בראיון?",
      "en": "Which challenge from Project Alpha would you describe in an interview?",
      "section": "Project Alpha",
      "type": "textarea",
      "required": false
    }
  ],
  "answers": {
    "CV_ALPHA_BULLET": "",
    "INTERVIEW_ALPHA_CHALLENGE": ""
  }
}
```

כל שאלה חייבת לכלול רק את השדות `key`, `he`, `en`, `section`, `type`, `required`. המפתח יהיה ייחודי באותיות אנגליות גדולות ובקו תחתון. `type` יכול להיות `text`, `textarea` או `checkbox`; `required` הוא `true` או `false`. השב/י בשתי השפות. כל מפתח ב-`answers` חייב להתאים למפתח שאלה במערך; ערך תשובה הוא מחרוזת או ערך בוליאני. אל תיצור/י תשובה לשאלה שלא ניתן לענות עליה מתוך החומרים.

## ייבוא

שמור/י את הפלט בקובץ JSON, פתח/י את Profile Builder ולחץ/י על **יבוא שאלות ותשובות (קובץ JSON)**. הקובץ נבדק בדפדפן; שדות או מפתחות לא מוכרים נדחים. לאחר מכן ניתן לבחור בין השאלות המובנות לשאלות שיובאו. תשובות חדשות ממלאות שדות ריקים; שינוי של תשובה קיימת מוצג כהצעה להשוואה ולא מחליף אותה בלי אישור. היעדר תשובה או שדה ריק לעולם אינם מוחקים מידע קיים.

אפשר להעתיק חומרים ואת ההנחיה לכל מודל AI. Profile Builder אינו שולח את החומרים למודל, אינו מבצע בקשות AI ואינו דורש מפתח API.
